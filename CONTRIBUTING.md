# Contributing to Open Inquiry Initiative

This initiative welcomes corrections, references, reproducible tests, and constructive challenges. The goal is transparent investigation, not consensus by popularity.

## Useful issue format

- **Project / claim ID:**
- **Observed behavior or disputed statement:**
- **Evidence or reproduction steps:**
- **Expected versus actual result:**
- **Environment / version / commit:**
- **Uncertainty, alternative explanations, or limitations:**

Please do not post personal information, private conversations, credentials, copyrighted third-party material without permission, or unsafe operational details. Do not assume that a speculative project is a validated result. Responses and review may take time; no service-level commitment is implied.

For code contributions, open a focused issue first when scope or licensing is uncertain. Each project repository may impose additional requirements.
